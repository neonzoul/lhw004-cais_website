# CAIS production release checklist

The GitHub Pages build is a public review prototype. Do not copy it to the production domain without completing these gates.

## School truth and rights

- Confirm official school name, phone, email, full postal address and exact map pin.
- Confirm curriculum wording, class-age/cutoff map, hours, terms, availability, fees and admissions steps.
- Confirm leadership roles, biographies, qualifications and portraits.
- Obtain publication permission for every child/staff image and video.
- Obtain educator approval for curriculum copy and the first article.
- Replace every prototype event/announcement with a dated, owned, current item.

## Enquiry and privacy

- Choose the form destination and named response owner.
- Confirm required fields, privacy notice, consent, retention and deletion process.
- Set visit/online-meeting scheduling and expected response time.
- Test successful delivery, error handling, spam protection and mobile completion.

## Search and AI discovery

- Remove `noindex,nofollow` from all approved production pages.
- Replace review `robots.txt` with the approved production crawl policy.
- Remove the public review banner and all presentation-only controls.
- Add canonical production URLs, XML sitemap and correct Open Graph image URLs.
- Update School and Article structured data only with confirmed visible facts.
- Validate structured data, titles, descriptions, links, favicon and social previews.
- Connect Google Search Console and analytics/consent under school-owned accounts.

## Quality and operations

- Optimize final images/video and verify Core Web Vitals on representative mobile devices.
- Run keyboard, contrast, text-resize, reduced-motion and screen-reader checks.
- Test every route, menu, gallery, form, external link and 404 behavior.
- Confirm CMS ownership, access, backup, updates and renewal responsibilities.
- Record launch date, production commit and rollback procedure.
